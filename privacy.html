Privacy Policy

Last updated: November 22, 2026

About This Application

Plex Docker Backups is a personal, non-commercial utility that uses rclone to back up Docker Compose configuration files to Google Drive.

Google Drive Access

The application accesses the owner's Google Drive account to upload, update, list, and maintain backup files. Google Drive data is used solely for these backup operations.

Data Collection and Sharing

The application does not collect personal information from other users, sell information, or share Google Drive data with third parties.

Data Storage

Backup files are stored in the owner's Google Drive account. OAuth credentials are stored locally on the owner's server and are not published on this website.

Data Retention and Deletion

Backup files remain in Google Drive until removed by the owner. The owner can revoke the application's Google account access at any time.

Contact

For questions about this privacy policy, contact the application owner through the GitHub repository.
